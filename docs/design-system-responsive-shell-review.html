State anatomy

Empty
What is absent, why it matters, relevant next action.
Loading
Stable reserved region, state label, no delayed financial-value animation.
Partial
Available answer, missing inputs, affected interpretation, completion path.
Stale
Text and icon/shape, absolute date, affected value, update path.
Validation error
Summary when multiple, first invalid focus, inline cause and correction.
Request error
What failed, what was preserved, retry or safe return.

Continuation anatomy

Offline
Connection state, retained local draft if supported, reconnect/retry route.
Success
What changed, reporting-currency result when relevant, logical next action.
Disabled
Native disabled semantics and visible reason nearby.
Destructive
Named consequence, separated action, cancel route, undo when feasible.
Unsaved
Preserved draft statement, continue editing, discard confirmation.
Unavailable
Non-enumerating copy and safe return, with no account or permission inference.

Guideline §§3.1, 8, 11, 12. Unavailable copy approved 2026-09-13.
